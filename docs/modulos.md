# Módulo Gestão de Contratos

O domínio de contratos passa a ser o primeiro módulo funcional desta cópia da base do Hub.

## Entidades
- Setor
- Fornecedor
- Contrato
- Permissão de usuário por setor (estrutura preparada)

## Funcionalidades iniciais
- Dashboard e KPIs
- Pesquisa, filtros e ordenação
- Grade/lista e paginação
- Detalhes e notificações
- Leitura e escrita por API
- Seed de dados reais do CSV inicial
